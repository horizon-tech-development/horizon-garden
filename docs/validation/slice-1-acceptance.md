# Slice 1 acceptance gates

- [ ] PASS: Workspace, property, garden, and all five growing-area types can be created.
- [ ] PASS: Rectangle length, width, and depth accept supported units.
- [ ] PASS: Area and soil-volume calculations are correct.
- [ ] PASS: Invalid dimensions are rejected clearly.
- [ ] PASS: SQLite data remains after closing and reopening the app.
- [ ] PASS: Editing preserves durable entity IDs.
- [ ] PASS: Migrations work for new and existing databases.
- [ ] PASS: Lint, type checks, tests, and web build pass.
- [ ] PASS: Linux Tauri development build launches.
- [ ] WARN until tested: Windows Tauri build compatibility.

Mobile, synchronization, catalog content, and visual crop placement are not part of Slice 1.
